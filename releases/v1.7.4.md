# v1.7.4 — 修复 Xray 临时配置扩展名与发布流程

## 本次修复
- 修复 `unsupported config file extension: config.json.tmp.*`：临时配置文件现在以 `.json` 结尾，兼容 Xray 26.10.21 的配置加载器。
- 保留 `-format=json`、配置有效性检查及原配置失败保护。
- 增加 Bash 语法、REALITY 密钥格式及临时配置文件名检查。

## 发布管理
- 增加 GitHub Actions CI，在提交和 PR 上运行测试。
- 在推送 `v*` 标签时检查脚本版本与标签一致，并自动从 `releases/vX.Y.Z.md` 创建 GitHub Release。
- 补录 v1.7.2 和 v1.7.3 的历史更新说明。

## Alpine 部署
```sh
apk add --no-cache bash curl jq
curl -fsSL https://raw.githubusercontent.com/yonghu996/vless-encryption-reality-alpine/main/install.sh -o /root/xray-menu.sh
bash /root/xray-menu.sh
```

> 本版本已根据真实安装错误修复源码；尚未在用户的 Alpine 主机上完成端到端运行验收。

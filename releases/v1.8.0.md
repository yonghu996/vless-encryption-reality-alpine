# v1.8.0 — Standard VLESS + REALITY + Vision for sing-box

## 新功能
- 支持第二种节点模式：普通 VLESS（服务端 `decryption: "none"`），继续使用 REALITY + Vision，适配不支持 VLESS Encryption 字段的 sing-box 1.13.x。
- 菜单新增 9「新增普通 VLESS（sing-box 兼容）」，通过独立 TCP 端口追加入站，不替换现有 ML-KEM-768 加密入站。
- 无交互模式：`bash install.sh install --mode standard --port 12774 --sni bing.com`。
- 菜单 8 显示现有加密节点和新增普通节点的链接。普通节点分享链接包含 `encryption=none`。
- 新增临时配置检查、原配置备份及服务失败时回滚；限制旧菜单 1/7 覆盖混合配置。
- 新增生成标准 VLESS 配置的回归测试。

## 示例
```sh
apk add --no-cache bash curl jq
curl -fsSL https://raw.githubusercontent.com/yonghu996/vless-encryption-reality-alpine/main/install.sh -o /root/xray-menu.sh
bash /root/xray-menu.sh
# 选择菜单 9
```

已有加密节点（例如端口 12773）保持原状；新普通节点建议使用 12774。确保 VPS 防火墙及云安全组允许新端口入站。

## 兼容和验收范围
- `settings.decryption = "none"`、REALITY 及 Vision 结构按 Xray 规范生成。
- 代码及脚本回归检查已编写；真实 Alpine 与 sing-box 1.13.11 的端到端连接仍待验证。
- 注意：旧菜单 1/7 暂不支持管理多节点，脚本会拒绝覆盖已存在的混合配置。请保留配置备份并使用菜单 9 追加节点。

# v1.7.5 — Alpine Xray 日志权限与 OpenRC 启动修复

## 修复
- 修复 v1.7.4 安装后配置测试成功，但 OpenRC 启动出现 `open /var/log/xray/error.log: permission denied`。
- 配置校验改为 Xray 专用用户运行，并提前修复 `/var/log/xray/error.log` 所有者及权限。
- 菜单「3. 重启 Xray」可修复旧安装的日志文件权限，不需要重新生成 UUID 或 VLESS/REALITY 密钥。
- 日志路径存在符号链接时拒绝自动修改，避免 root 跟随非预期路径。
- 将 freedom 弃用的 `settings.domainStrategy` 迁移到 `streamSettings.sockopt.domainStrategy`，减少新版 Xray 的弃用警告。
- 新增 Bash 回归检查。

## 从 v1.7.4 恢复

```sh
curl -fsSL https://raw.githubusercontent.com/yonghu996/vless-encryption-reality-alpine/main/install.sh -o /root/xray-menu.sh
bash /root/xray-menu.sh
```

如已有配置，选择菜单 `3` 可直接尝试恢复现有节点；若从未成功生成配置则选择菜单 `1` 安装。网络端口仍需在主机防火墙及安全组开放。

> 根据用户提供的真实错误日志实施修复；实际 Alpine 机器的端到端验收仍待执行。
